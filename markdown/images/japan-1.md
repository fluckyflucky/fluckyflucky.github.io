# 第一次日本行

## 人生第一次出国，居然是背着爸妈偷偷去的……

一次很难忘的经历，也是真正意义上第一次找到了自己乐在其中的事。如果没有这次冒险，我也许就再也不会（也许是不敢）迈出脚步。

虽然有些自大，但是感觉我这一趟也带动了几个朋友😋

虽然都是做了约定一起旅行，但是最后却迫于各种现实因素，变成了大家各自去……

希望有一天能和朋友们一起去啊。
