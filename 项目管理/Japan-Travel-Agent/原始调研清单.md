# Japan Travel Agent — MCP / Skill / Tool 调研清单

> 日本旅行 Agent 可用的数据源、MCP、Skill 与 Tool 调研。
>
> 当前主要覆盖：
>
> - 日本铁路 / 地铁 / 巴士 / 船舶等地面交通
> - 景点 / 季节 / 旅行信息
> - 国际及日本机票搜索
> - Google Flights / KAYAK / Skyscanner / 携程 / 飞猪等 OTA 数据
> - 正规航空 API / Agent-native booking API

---

# 1. 日本交通

## 1.1 駅すぱあと API MCP Server

- **项目**：ValLaboratory/ekispert-api-mcp-server-docs
- **类型**：官方 MCP
- **数据源**：駅すぱあと API
- **URL**：https://github.com/ValLaboratory/ekispert-api-mcp-server-docs
- **特点**：
  - 駅すぱあと官方提供。
  - Streamable HTTP MCP。
  - 支持铁路、巴士、飞机、船等交通方式。
  - 支持站点搜索。
  - 支持地址 → 周边站。
  - 支持经纬度 → 周边站。
  - 支持多地点 / 经由点路线搜索。
  - 支持发车时间、到达时间、始发、终电等条件。
  - `viaList` 可以使用站名、站码、地址、经纬度。
- **限制**：
  - 需要駅すぱあと API Access Key。
  - 商业 API。
  - 部分时刻表数据可能涉及额外授权。
- **用途**：
  - 很适合作为未来生产环境的正规交通 Provider。
  - 非常值得参考其 MCP Tool Schema。

## 1.2 japan-transit-mcp

- **项目**：Anchovy-s3/japan-transit-mcp
- **类型**：MCP
- **数据源**：Transit API / GTFS / ODPT 等
- **URL**：https://github.com/Anchovy-s3/japan-transit-mcp
- **主要 Tools**：
  - `suggest_places`
  - `suggest_stations`
  - `reverse_places`
  - `plan_route`
  - `guidance_plan`
  - `get_station`
  - `station_departures`
  - `list_feeds`
  - `list_operators`
- **特点**：
  - 免费公共 Transit API。
  - 支持地点 / 站点搜索。
  - 支持经纬度作为路线 endpoint。
  - 支持附近站点。
  - 支持始发 / 终电。
  - 支持 Departure Board。
  - 可以查询底层 GTFS / ODPT 数据来源和 attribution。
- **用途**：
  - 非常适合旅行 Agent 第一版直接接入。
  - 可以作为免费路线规划 Provider。

## 1.3 norikae-mcp

- **项目**：tysonwu/norikae-mcp
- **类型**：MCP / 网页数据封装
- **数据源**：Yahoo! 乗換案内
- **URL**：https://github.com/tysonwu/norikae-mcp
- **主要 Tool**：
  - `search_route`
- **能力**：
  - 日本站到站路线搜索。
  - 最多三个经由站。
  - 指定出发时间。
  - 指定到达时间。
  - 始发。
  - 终电。
  - IC / 现金票价。
  - 自由席 / 指定席 / Green Car。
  - 按时间 / 换乘 / 价格排序。
  - 可分别允许或禁止：
    - 飞机
    - 新干线
    - 特急
    - 高速巴士
    - 普通巴士
    - Ferry
- **特点**：
  - `npx norikae-mcp` 即可运行。
  - 非常适合 PoC。
- **限制**：
  - Yahoo! 乗換案内网页数据。
  - 长期稳定性与 ToS 需要单独考虑。
- **用途**：
  - 快速验证日本旅行 Agent 的交通规划能力。

  - `get_local_food`
  - `get_festivals`
  - `get_traditional_arts`
  - `get_japan_heritage`
  - `get_entity_full`
  - `plan_feasibility_check`
- **特点**：
  - 免费。
  - 无 API Key。

## 3.4 kayak-headless-mcp-server

- **项目**：Shuangbing/kayak-headless-mcp-server
- **类型**：MCP / Headless Browser Scraper
- **数据源**：KAYAK
- **URL**：https://github.com/Shuangbing/kayak-headless-mcp-server
- **实现方式**：
  - Headless Chromium 打开 KAYAK。
  - 获取 Cookie 和 Headers。
  - 缓存 Session。
  - 调用 KAYAK 后端搜索。
  - Poll 至搜索完成。
- **主要 Tool**：
  - `search_flights`
- **输入**：
  - Origin。
  - Destination。
  - Departure Date。
  - Return Date。
  - Adults / Children / Infants。
  - Direct Only。
  - Sort。
- **返回**：
  - Price。
  - Currency。
  - Provider。
  - Provider Code。
  - Booking URL。
  - 航班号。
  - 起降机场。
  - 起降时间。
  - Stops。
  - Stop Airports。
  - Duration。
- **特点**：
  - KAYAK 本身已经是 OTA Aggregator。
  - 一个 Provider 可以间接看到：
    - Trip.com
    - 航司官网
    - 其他 OTA
- **用途**：
  - 很适合作为 OTA 实时价格验证 Provider。
  - 非常值得研究其 Session / Headless Browser 实现。

底层 Provider 可以自由切换：

```text
FlightSearchTool

├── GoogleFlightsProvider
├── ITAMatrixProvider
├── KayakProvider
├── SkyscannerProvider
├── TravelpayoutsProvider
├── CtripProvider
├── FliggyProvider
└── AmadeusProvider
```

Agent 本身不需要知道当前实际使用的是哪个数据源。

这样后续某个网页 Scraper 挂掉、API 涨价或需要换 Provider，都不会影响上层 Agent 的 Tool Contract。
