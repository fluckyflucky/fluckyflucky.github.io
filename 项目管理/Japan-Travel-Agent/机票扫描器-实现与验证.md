# 机票扫描器：实现与验证

验证日期：2026-10-03（北京时间）。页面：`/#/tools/flights`。

## 已实现

- Vue / TypeScript 纯前端，直接请求 ITA Matrix 的公开网页接口，无后端、个人 API Key 或 CF 代理。
- 多个出发地 × 多个目的地 × 闭区间内每天，按用户设置的随机间隔启动请求，无需等待上一项返回；默认同时查询上限 6，可设置为 1–12。可随时停止所有在途请求及待发任务。
- 支持常见中文城市名及机场/城市三字码；固定单程、1 成人、经济舱、人民币。
- 显示进度和按价格排序的结果。localStorage 以 `日期:出发地:目的地` 保存最新结果，不记录历史；每项成功后立即保存。失败保留旧数据并标出失败，空报价会覆盖之前结果。
- 保存查询条件；首次打开需手动扫描，之后可选择重新打开自动刷新。更换日期或城市后重置上一轮进度。支持交换出发/目的地、停止后继续未完成项及重试失败项；成功项不重复查询。
- 展示与最低报价匹配的航班摘要，附 Google Flights 查票链接；报价不是预订承诺。支持只看有报价、按价格或日期/航线排序；扫描时分别显示查询中、待发、成功及失败数。

## 验证与 review

- `pnpm build`：通过 TypeScript 检查及生产构建。
- `pnpm test:flights`：隔离 Chrome 上下文验证组合遍历、进度、无报价、本地缓存重载、失败保留、停止、重新打开自动刷新、中文城市映射、375 / 768 / 1440 像素宽度无横向溢出。
- `FLIGHTS_LIVE=1 pnpm test:flights`：真实浏览器从 localhost 直接请求 Google 的 Matrix 接口，验证 CORS、报价和持久化。PVG → NRT，2026-11-10，返回 CNY 1300，Jetstar GK36；仅为当次样本。
- review 检查请求取消/超时、报价与航班关联、更新失败后旧缓存状态、路由入口和源码许可；未发现阻止提交的问题。
- 桌面与移动端截图检查通过。全页截图时暂时隐藏网站原有动画 canvas，避免截图拼接伪影；产品代码未改动动画。

## 接口与许可

接口协议参考 [YogevKr/itamx](https://github.com/YogevKr/itamx)，MIT 声明保存在 `src/tools/itamx-NOTICE.txt`，并复制到静态站点 `/third-party/itamx.txt`。

代码使用 Matrix 网页应用公开的应用 key，用户无需配置自己的 key。该接口不是面向第三方保证稳定的正式 API；目前直连实测可用，未来可能改动。随机间隔用于降低请求频率，不保证免于限流。没有实现接口失效后的代理或多数据源切换。

第二版额外验证：延迟响应时按间隔重叠发起、同时查询上限、乱序返回结果归属、停止后不继续发请求及迟到结果不覆盖缓存、只继续未完成项、失败重试、筛选和排序。命令 `FLIGHTS_LIVE=1 FLIGHTS_LIVE_PARALLEL=1 pnpm test:flights` 同时实测 PVG → NRT / KIX（2026-11-10）：启动间隔 1001 ms，第一份响应耗时 20686 ms；NRT 返回 CNY 1410，KIX 返回 CNY 1717。第二个请求早于第一个响应，两项均成功写入缓存并通过重载验证。报价仅为当次样本。

浏览器测试默认使用录制报价，不产生真实网络扫描；只有设置 `FLIGHTS_LIVE=1` 才查询真实接口。可通过 `FLIGHTS_TEST_URL` 指向部署页面。
