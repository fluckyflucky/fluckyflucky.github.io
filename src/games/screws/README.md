# 拧螺丝

入口：`/#/games/screws`。40 个固定关卡，点击螺丝，再点击可用空孔。前 10 关沿用原布局，后 30 关增加交叉、斜撑和叠板。

- 螺丝数量不变，只能搬移；同一孔上的螺丝固定所有经过该孔的木板。
- 最上层木板的实心部分会遮住下面的孔，遮住时不能操作。
- 木板两端都没有螺丝就掉落。停放到另一块木板的孔里，会固定那块板。
- 顶部四个孔用于临时停放。还有撤销、重玩和安全停放提示。
- localStorage 键：`aoinatsu:screws:v1`，保存当前局面、解锁关卡和各关最佳步数。撤销历史只保留在本次页面会话中。
- 原 10 关存档会补齐后 30 关的成绩栏，保留当前关卡、解锁进度和局面。

玩法参考：[我爱拧螺丝](https://www.7k7k.com/swf/209226.htm)。木板和螺丝用 SVG 绘制。

运行规则测试（Node 22.6+）：

```sh
node --experimental-strip-types scripts/test-puzzles.mjs
```
