# 拧螺丝

入口：`/#/games/screws`。40 个固定关卡，点击螺丝，再点击可用空孔。使用 Matter.js 模拟重力、铰链和板间碰撞。

- 螺丝数量不变，只能搬移；同一孔上的螺丝固定所有经过该孔的木板。
- 最上层木板的实心部分会遮住下面的孔，遮住时不能操作。
- 两颗螺丝固定木板；拆掉一颗后绕剩下的螺丝摆动，最后一颗拆掉后自由下落。板间会碰撞，落到视口下方才计为拆除。
- 孔的位置跟随木板运动；遮挡使用旋转后的几何形状。木板孔与底板孔对齐时，可以重新插入螺丝固定。
- 初始交叉叠板属于不同深度，先保留重叠；两块板分离后启用相互碰撞，避免物理引擎一开局就强行挤开原布局。
- 螺丝有独立的固定碰撞体，摆动和下落的木板会被挡住；自身支点处是钻孔，不与自身螺丝碰撞。初始被上层板遮住的螺丝在露出后启用碰撞，支撑木板的螺丝仍可操作。
- 顶部四个孔用于临时停放。还有撤销、重玩和安全停放提示。
- localStorage 键：`aoinatsu:screws:v2`，保存板的位置、角度、速度、螺丝支点和关卡进度；旧 v1 存档迁移关卡和局面，旧版最佳步数清零。撤销可恢复移动前的物理快照。
- 进入页面先展示当前关卡的完整开局；有旧局面时显示“继续上次”，明确点击后才恢复。未操作新局时保留原存档，开始新局或重玩后替换。

玩法参考：[我爱拧螺丝](https://www.7k7k.com/swf/209226.htm)。木板和螺丝用 SVG 绘制。

运行规则测试（Node 22.6+）：

```sh
node --experimental-strip-types scripts/test-puzzles.mjs
node --experimental-strip-types scripts/test-screw-physics.mjs
```
