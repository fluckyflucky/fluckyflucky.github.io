# 对齐审查 · 更新于2026-10-01

结论：仍没有支持整体80%或90%对齐的证据，这份记录不是对齐验收批准。用户随后将要求调整为“基本能玩”，要求清理冗余并再次明确push，本批按新指令做阶段发布。具体修正与验证见 [本轮修复记录](FIX-REVIEW-2026-10-01.md)。下面较早批次的记录保留为历史，不表示新规则仍沿用旧值。

## 基准与统计

以《风云变幻》常规规则为基准，不把秘密结社、英雄等额外模式列为本轮必选。百科解锁列表保留全部原始ID，但不能把列表中的名称当作已实现玩法。

- 科技数据77/77、市政数据61/61：前置、成本、时代、提升条件均来自带来源URL的事实记录。
- 已有55个可生产条目，其中17种单位；只对百科提供明确基础成本/战斗数据的字段应用来源值，未提供字段不猜填。
- 政体槽位数据13/13、可用政策43张、文明3个；52/126个提升条件仍未实现。完整政体效果仍不足，不能把槽位数据当成完整玩法。
- 数据覆盖率不等于玩法对齐率；目前没有可支持整体90%的证据。

## 本次修正

- 科学胜利：火星之后还有系外行星远征，抵达后才获胜；太空阶段可分城市完成，不可重复建设同一阶段。
- 文化胜利：按各文明的历史文化及分目标旅游累计值计算游客，不再使用固定1000阈值或大众传媒门槛。著作、主题、边境和政体修正仍未齐全。
- 区域：工业区计算成对矿山/伐木场及水渠、水坝、运河等邻接；学院取消自创基础科技。水渠改为需要选址的非专业区域，住房区分淡水、海岸和内陆。
- 战斗：已有单位的近战、远程、轰炸数值分开，去掉民族主义给所有军队+5的自创效果。
- 政策：13种政体槽位和前置取自来源；修正寡头、君主和商人共和国的2021年槽位。43张卡实际接入解锁、淘汰和专属限制；理性主义只加成学院建筑且检查人口15/原始邻接4，邻接卡不放大人口或建筑基础产出。使者联盟只将首个使者计为2，不将收益翻倍。单位维护费采用来源基础值，征兵减费逐单位截断为0，生产加成相加而非相乘。民主贸易加成只适用于宗主城邦并惠及双边，未把普通友谊冒充同盟。
- 政体：古典共和住房/宜居度要求已有区域；寡头只加近战/抗骑兵/海军近战，侦察兵、骑兵不受益；去除商人共和国的错误贸易容量和无条件金币。总督依赖效果暂不发放，并在面板提示。后期政体接入生产、文化、旅游、战力和战略资源加成，电力及完整外交效果仍阻断。
- 提升：普通山脉不触发占星术；击杀条件区分投石兵与蛮族；两座学院只鼓舞历史记录，不能代替大科学家触发教育。
- 地块：数据可表达基础地形、丘陵与森林叠加；农场按封建主义/零件规格化计算实际邻接，矿山分阶段升级。
- 存档：v3保留v1/v2原始数据、研究ID和旧手动快照。旧版没有游客分文明累计值，不能准确重建该历史；没有合法空地的旧水渠计划会拒绝迁移并保留原始数据。
- 界面review：购买价格、是否买得起及实际扣款共用同一个折扣函数，避免按钮拦截本应买得起的民主/神权购买。
- 排版与文案（10月1日）：去掉英文装饰副标题、重复说明和面板固定高度；压缩顶部留白、卡片间距。政体选择、政策槽和应用按钮先显示，13种政体列表默认折叠。手机政策、外交、胜利卡片采用两列；政策效果、研究规则、胜利条件和存档说明使用SVG提示按钮，支持hover、键盘聚焦和手机点击，手机提示正文16px。费用、实际数值、清档风险与未实现内容仍保留。
- 可变开局：新增1–5个AI、指定/随机文明，固定设置和种子可复现。两座城邦保持不变，4–5个AI自动扩大地图；旧v3缺少人数配置时保留原始ID。胜利、旅游、压力、外交、使者、历史和校验均按实际人数计算，不再假定三个主要文明。
- AI：保存四类发展偏好和探索记录；研究沿前置链评分，生产结合住房、战争与偏好；探索、撤退和攻击使用可见目标，AI能与其他AI开战/停战。保留政策费用与外交保护期，不宣称复现Firaxis决策。另跑3个种子、每局6个主要文明的160回合模拟，两局观察到宣战/停战，一局未发生战争。
- 传教士：依据百科修正基础购买150信仰、4移动力、3次传播及祠堂前置，不要求神学。本城宗教条件也参与购买校验；神权/速度折扣与界面仍共用价格函数。连续购买涨价和外来宗教尚未实现。
- 宣战：玩家和AI共用外交状态变更，立即取消敌对双方贸易；按百科条件给被宣战方防御战术鼓舞，主动宣战及失败请求不触发。首次相遇会互相记录并分别获得写作尤里卡。
- 地图：原`2 / 0 / 0`为粮食/生产力/金币，改为对应图标和非零数值，按条目数居中；附图例及市民工作条件。嫩芽切换图层，指南针仅重定位视野；工具支持hover、键盘及500ms触屏长按，移动手指取消，长按松手不执行操作。
- 提示回归：修正blur与pointerleave同时触发时遗留关闭计时器的问题，避免新打开或已固定的提示被旧计时器关闭。传教士卡片不再显示不可用的生产成本/回合数。

## 验证与发布门槛

### 后续修复（80分请求）

区域成长、折扣、锁价及暂停位置，战斗随机范围和伤兵减战力，分数权重与同分判定已修正。城邦可选2–6个，默认3个使政治哲学鼓舞可达；新增六类型、政体影响力、对应建筑使者收益、部分宗主奖励和战争联动。宗教新增实际预言家、名额、六个万神殿及12个信条，不再以40点+60信仰按钮直接创教。旧两城邦ID、旧队列基础造价和缺失新字段的存档继续兼容。

继续批次增加九位科学家的共享名单、实际单位与能力，玩家和AI都可争抢、移动和激活；图书馆/大学永久加成、圣地局部加成及治疗分别结算。启蒙运动鼓舞现在由三位实际招募的科学家/预言家触发，不使用旧版泛用奖励计数。

这没有补齐原作整体：当前51个提升和12项系统级阻断仍在；完整伟人竞争、宗教单位/神学战、城邦任务/征兵、忠诚度/总督/时代、议会/电力气候等缺口未被移除。新增回归数量不是游戏评分，不将测试数量冒充“80分”。

### 审查方法

`pnpm test:civilization` 分别执行引擎回归和独立来源/规则用例；`pnpm build` 执行类型检查与静态构建。浏览器测试使用隔离上下文，验证375/768/1024/1440px的建城、研究、政体政策、回合、自动存档、刷新和进度页面，不接触用户浏览器的存档。额外检查默认政体面板高度、完整列表展开、提示边界及hover/点击/聚焦/Escape/外部点击，以及375×667触屏展开模式。

`pnpm civilization:audit` 当前必须失败；完整阻断项见 `release-readiness.ts`。不得靠减少分母、显示百科名称、修改测试预期或删除阻断项来宣称90%。清除每项需要实现规则、补上来源用例及实际游玩证据。

当前review仍有P1：政体/政策/文明特性覆盖不足；伟人与著作、宗教、城邦和军事规则不完整；忠诚度、总督、时代、间谍、世界议会、外交胜利、电力、气候与灾害缺失。未来时代树随机化和部分科技效果也待实现。

本轮验证：31项引擎回归、29项来源/规则回归，共60项；包括三文明/三难度的完整回合模拟、200种人数/地图/种子组合、1–5个AI的可重复对打、实际攻击/低血量撤退和严格存档校验。静态构建通过（项目原有vendor大包仍有体积警告）。四档宽度浏览器回归通过，另含真实触屏长按/移动取消、双重离开事件、随机文明、1/5个AI开局与刷新及传教士实际购买；截图检查375px开局与外交无横向溢出。规则测试通过不改变发布审查失败结论。

百科部分总述和实际资料片数值存在版本差异；进一步实现时需用原作资料片游戏数据或官方版本说明交叉核验，不能把网页路径中的gathering-storm视作每段文字均已更新。
