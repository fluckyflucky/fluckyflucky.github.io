# 10月4日：现有交互修复

本轮停止扩展系统，处理实际试玩暴露的研究、生产和展开布局问题。不改变存档版本，也不删除旧进度。

## 原因与修改

- 研究树原来仅按前置深度分列，同一列混入不同年代，却拿第一条的时代当整列标题。现在时代分区不重叠，前置连线始终由左到右，标题随纵向滚动保留。
- 未来时代百科不列随机前置，空数组被当成开局入口。研究判定、AI路线、连线和详情现在共用后期前置。本版仍使用固定后期路线，不宣称已实现原版随机未来树；旧档已投入值保留，旧档正在研究的非法入口在推进时转到合法研究。
- 对照百科科技／市政导航，修正卫星→信息时代、飞行→现代、探索／人文主义→文艺复兴。抓取脚本原来在整段要求里查找时代字符串，误中了“现代航空”“中世纪集市”和提升条件里的时代名；改为只读要求中的时代字段，增加离线解析回归。
- 新城不再替玩家自动排纪念碑；罗马已有纪念碑照常保留，AI仍自行安排生产。旧档队列不变。
- 生产列表检查实际可放置地块，不再把无合法地块的区域／奇观列为可建；显示未解锁时给出原因。购买判定与按钮共用出生格、价格和资源检查，失败不扣钱。
- 取消后续建显示锁定造价、已有投入及剩余回合，零产出不显示 Infinity。研究切换走引擎入口，不再直接写研究ID。
- 去掉把“百科解锁”称为“已可建设”的错误提示。搜索会定位匹配节点，可切换结果、跳时代、回到当前研究；已完成／正在研究／终局状态不会显示可点击的开始按钮。
- 展开视图使用满视口工作区，顶栏与下一回合不随面板滚走，研究树内部滚动。收紧摘要、节点、城市概览和生产队列，建筑效果保留在点击／长按说明里。沿用 UI/UX 技能的44px触控、焦点和移动视口检查项；技能搜索脚本缺失，未安装替代包。

# 10月5日：研究连线、开局流程与文案

## 研究树

- 科技／市政仍保留全部198条有效前置关系与时代分区。节点改为184×92，列间通道72px、行间通道36px；按相邻前置／后续排序，跨列线走行间通道。
- 同一对列中分支顺序相反的边对，科技从66对降至7对、市政从41对降至3对。该指标不代表所有几何交叉；连线仍可能交叉，但不会穿过卡片。选中节点仅突出直接前置和后续，箭头表示方向。
- 回归逐段检查每条折线与所有节点的矩形，确认不进入节点内部；同时检查节点不重叠、边不丢失、布局确定性以及浏览器中的实际卡片内容不裁切。

## 开局对照

依据[文明六官方手册](https://downloads.2kgames.com/civilization/vi/manuals/eu/CIV_VI_25TH_ONLINE_MANUAL_ENG.pdf)第108–112页、[建城](https://www.civilopedia.net/en-US/gathering-storm/concepts/cities_2/)、[科技树](https://www.civilopedia.net/en-US/gathering-storm/concepts/science_4/)、[市政树](https://www.civilopedia.net/en-US/gathering-storm/concepts/culture_4/)及[政策](https://www.civilopedia.net/en-US/gathering-storm/concepts/govt_2/)条目核对。

| 流程 | 检查／修正 |
| --- | --- |
| 新游戏与开局单位 | 文明、人数、地图、难度、速度、种子设置保留；玩家开拓者与勇士正常生成，开局选中开拓者。 |
| 建立首城 | 开拓者消失，城市建立并显示生产面板；玩家生产队列保持空白，罗马自带纪念碑保留。 |
| 首次科技选择 | 移除默认制陶术。首城建立后出现科技待办，开局只有畜牧业、占星术、制陶术、采矿业、航海术可研究。 |
| 首次市政 | 保留默认法典。完成后停止，不再替玩家选后续市政。 |
| 科技完成／切换 | 完成后等待玩家选择下一项。保留原项目投入，溢出与强制跳过回合时未分配的科学／文化分开保存，下一次推进投入已选项目。 |
| 法典与政策 | 不再替玩家装上纪律和城市规划；出现政策待办。法典未解锁时禁用应用按钮。 |
| 回合待办 | 加入科技、市政、空闲政策槽；导航显示小圆点，确认中的“去处理”进入对应面板。单位跳过／驻守和生产待办仍按原规则。 |
| 展开／收起地图 | Teleport移动DOM后滚动坐标归零，首城落到视野外。布局更新后重新定位选中地块，展开和收起均测试首城完整可见。 |

旧存档的当前研究、已完成项目、生产队列和政策不改写。新增可选的科学／文化溢出字段，不改变存档版本；缺字段的旧档可读，负数、非数值和缺键的新字段拒绝读取。之前非法未来入口自动转到其他科技的行为也改为等待玩家重选，已有未来投入保留。AI仍自行选择和连续研究。

仍有明确差异，未借本轮改动声称全部复刻：不支持原版战斗／平民／支援单位同格和护送；AI／城邦开局预先建城；研究树尚不支持点击远期目标自动排前置；地图、难度与领袖名单也仍为现有子集。

## 界面文字

删除无用的英文副标题和残留样式、每次选择研究时重复的教学通知、旧版地图数字解释、无解锁节点的“查看百科”占位文案。种子和城邦鼓舞说明放入设置问号；存档覆盖警告、规则条件及未实现差异保留。布局按UI/UX的44px触控与键盘焦点要求检查，文案按humanizer只删改冗余，不增加宣传语。
