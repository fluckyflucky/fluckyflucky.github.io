# 奶龙似方块

10×20 可见棋盘，另有四行隐藏生成区。七种四格方块，七袋随机、SRS 顺逆时针旋转、墙踢、暂存、三个预告、落点轮廓、加速下落及落底。满行一起清除，整行上移补空，格子不单独掉落。500ms 落地锁定，最多 15 次移动或旋转重置；无效操作不重置。生成位被占或方块完全锁在隐藏区即结束。

基础消行 100/300/500/800 分，乘当前等级；每十行升一级。软落每格一分、硬落每格两分。支持三角检测的 T-spin、Mini、连击、连续高难消行奖励及全消奖励。不宣称官方授权或完整竞技规则认证。

两张整图固定对齐棋盘，不在单格重复贴图。微笑图为底层；用户提供的侧目图只通过所有实际占用格组成的 SVG 裁切区域显示。活动方块也算占用，落点轮廓不算。方块移动、锁定或消行后，裁切区域由当前局面重新计算。暂停不改图。

规则与操作参考 [Tetris Mobile 操作说明](https://playstudios.helpshift.com/hc/en/16-tetris-mobile/faq/2944-tetris-controls/)、[现代方块规则实现说明](https://github.com/saddambaialiev/tetris)。规则引擎为本项目实现，不复制其他游戏代码。图片来源见 [素材表](../frogArt/ASSETS.md)。存档和最高分只存浏览器 localStorage，进入页面先暂停；离开、后台或失焦会停表并释放按键。

检查 `node --experimental-strip-types scripts/test-frog-games.mjs`，包含旋转、墙踢、锁定计时、消行、暂存、顶出、计分及 100 局压力测试。
