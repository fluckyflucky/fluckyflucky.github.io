# 合成大奶龙

奶龙与奶蛙使用同一套物理规则，素材、当前局面和最高分分别保存。相同等级接触后合成，下落间隔 650ms；最终等级保留在桶中，危险线持续溢出才结束。

物理使用 [Planck / Box2D](https://github.com/piqnt/planck.js)。圆球是真正的圆形碰撞体；固定 120Hz 外层步长，每步至少细分三次，快速运动时继续细分，把单步移动限制在约 1px。整个接触堆一起解算，不使用局部 TOI 解算，也不跨不同子步长复用接触冲量，避免局部挤压和冲量缓存放大能量。顶部不设碰撞天花板，球不休眠，失去支撑后会下落。投放时仅带一次很小的横向初速度，不添加每帧“滚落”力。

合成在两球质心生成，传递线动量，初始旋转按目标大小的转动惯量计算。新球从可用空隙长到目标半径，每个子步最多增长 0.5px，让接触约束把邻球挤开；相同等级接触即可继续连锁。质量随直径增长、最大比例约 11:1，增长期间质量不变。等级提升和尺寸增长属于游戏事件，不是质量、能量守恒的真实物质融合；普通运动、摩擦、碰撞和转动由引擎求解。

旧存档继续兼容。新增角速度、增长半径、危险线计时和投放冷却字段，刷新不会重新开始增长或清掉溢出计时。存档仍只保存在浏览器，不发送到服务器。

运行 `node --experimental-transform-types scripts/test-dragon-merge.mjs` 检查失去支撑、单点滚落、双点托架、快速碰撞、合成挤压、旧存档和 30 组随机连续投放。可在命令末尾指定种子重现单个局面。
