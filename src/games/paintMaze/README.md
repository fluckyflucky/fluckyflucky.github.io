# 涂色迷宫

入口：`/#/games/paint-maze`。30 关，方向键 / WASD、屏幕滑动或方向按钮操作。

- 每次滑到墙前才停，路过的格子染色；全部道路涂满就过关。
- 固定地图位于 `levels.ts`，包含岔路、环路和错位挡墙。11–20 引入大片空地；21–30 为 17×17 至 21×21 高难地图，至少 6×6 空地、30 个可达停靠选择点。可直接进入第 11 或第 21 关。
- 新增地图经离线生成筛选后固定到源文件，不在浏览器随机生成。验收要求所有可达停点都能继续涂满，提示路线至少 100 次滑动（不是最优解步数）。
- 关卡测试除检查涂满外，还检查岔路数量、环路数量和滑动停靠图上的分支，避免把“可通关”误当成“有路线选择”。
- 提示从当前位置搜索通向未染色道路的最短路线，标出第一步方向。
- localStorage 键：`aoinatsu:paint-maze:v2`，保存当前局面、解锁关卡和各关最佳步数。旧 v2 的 10/20 关存档完整保留，仅追加成绩栏；旧 v1 地图则只迁移解锁进度，不复用局面。

玩法参考：[AMAZE! 官方应用页面](https://play.google.com/store/apps/details?id=com.crazylabs.amaze.game)。

运行规则测试（Node 22.6+）：

```sh
node --experimental-strip-types scripts/test-puzzles.mjs
```
