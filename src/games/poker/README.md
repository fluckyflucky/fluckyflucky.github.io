# 德州扑克

四人无限注牌桌（玩家 + 三机器人），初始各 1000 虚拟筹码，盲注 10/20。仅消遣，无真钱、支付、充值或提现。

- 标准五张最佳牌型，从七张牌组合选取，A 可组成 A2345；同牌型比较所有踢脚。
- 庄位轮转；单挑时庄家小盲，翻牌前先行动、翻牌后后行动。
- 过牌、跟注、弃牌、加注、全押；最低完整加注、不足额全押不重新开放加注权。
- 按累计投入分层结算边池；平局分池，无法平分的余数按庄家左侧顺序分配。
- 本桌 27：2、7 不同花独赢主池（含诈唬），每名本手参赛对手另付 20；平局不发奖，支付不超过剩余筹码。只有边池获胜不触发奖金。
- 机器人用自身底牌、公共牌、底池和行动信息估算胜率，不读取其他底牌或实际剩余牌堆。三种不同激进度，27 会增加诈唬概率。
- 所有筹码始终共计 4000，输光可重开。页面隐藏或离开时机器人停止行动；牌桌完整存于本地 `aoinatsu:poker:v1`。

规则参考：[PokerStars 下注、边池、单挑规则](https://www.pokerstars.com/help/articles/poker-rules-master/229192/)、[Seven Deuce 变体说明](https://coinpoker.com/games/seven-deuce/)。27 没有统一奖金标准，本桌按用户确认的不同花规则与固定虚拟奖金执行。

测试：`node --experimental-strip-types scripts/test-table-games.mjs`。
