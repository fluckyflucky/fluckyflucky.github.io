# 德州扑克

六人无限注牌桌，座位可设为玩家、机器人或空位。必须有一名玩家和至少一名机器人；初始每位 1000 虚拟筹码，盲注 10/20。仅消遣，无真钱、支付、充值或提现。

- 标准五张最佳牌型，从七张牌组合选取，A 可组成 A2345；同牌型比较所有踢脚。
- 庄位轮转；单挑时庄家小盲，翻牌前先行动、翻牌后后行动。
- 过牌、跟注、弃牌、加注、全押；不足额全押不单独重新开放加注权，连续短码全押累计达到一次完整加注额时会重新开放。
- 按累计投入分层结算边池；平局分池，无法平分的余数按庄家左侧顺序分配。
- 本桌 27：2–7 独赢主池（含诈唬，同花也算），每名本手参赛对手另付 10 个大盲，即 200；平局不发奖，支付不超过剩余筹码。只有边池获胜不触发奖金。
- 每个机器人可选择紧凶、松凶、紧弱、松弱。仅使用自身底牌、公共牌、底池和行动信息估算胜率，不读取其他底牌或实际剩余牌堆。27 会增加诈唬概率。
- 更改风格可保留当前手牌。换座或增减人数需点击“重开并应用”，每位筹码回到 1000。
- 筹码总数随入座人数为 2000–6000，结算始终守恒。页面隐藏、暂停、打开设置或离开时机器人停止行动。
- 存档继续使用 `aoinatsu:poker:v1` 键，内部版本升为 2。旧四人桌迁移为四个入座、两个空位，保留手牌与筹码。

规则参考：[PokerStars 下注、边池、单挑规则](https://www.pokerstars.com/help/articles/poker-rules-master/229192/)、[Poker TDA 第 47 条](https://www.pokertda.com/view-poker-tda-rules/)、[Seven Deuce 变体说明](https://coinpoker.com/games/seven-deuce/)。27 没有统一奖金标准；本桌按此前确认的 10 大盲、同花也算执行，与只算不同花的版本有区别。

测试：`scripts/test-table-games.mjs`、`scripts/test-poker-settings.mjs`（用 Node `--experimental-strip-types` 运行）。涵盖全部人类座位、空位、30 个单挑座次、四种机器人决策差异、边池、短码全押、筹码守恒和旧存档。
