# 扫雷

- 9×9、10 雷；25×25、100 雷。后者为本网站自定义尺寸。
- 按用户要求，普通随机盘，只保证第一次开格不触雷，不保证邻格无雷，不验证可解性；后面可能需要猜。
- 首次开格才生成，随机打乱除首格外的所有格子，选出指定数量的雷。生成后不挪雷、不暗中保命。
- 简单数字提示不读取隐藏雷，也不把手动标旗当推理前提。没有确定步骤时明确提示可能需要猜。
- 支持右键 / 长按标旗、开格 / 标旗切换、数字格开邻格、逻辑提示、24–36px 格子调节。棋盘仅横向滚动，纵向使用页面滚动。滑动不触发开格。
- 方向键移动焦点，Enter 开格，F 标旗；浏览器组合快捷键不被游戏拦截。
- 存档 `aoinatsu:mines:v2` 含盘面、已开格、旗子和计时；加载检查雷数、数字和输赢状态，不检查是否可解。旧版其他尺寸不迁移。

测试：`scripts/test-table-games.mjs`、`scripts/test-arcade-rules.mjs`（用 Node `--experimental-strip-types` 运行）。覆盖雷数、首点、标旗、连开、误标踩雷、公开信息提示和输赢存档。
