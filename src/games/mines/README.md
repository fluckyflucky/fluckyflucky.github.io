# 扫雷

- 99 雷：经典专家尺寸 30×16、99 雷。
- 50×50：50×50 地图、500 雷（用户确认地图尺寸，雷数采用 20% 密度）。
- 按用户要求，普通随机盘，只保证第一次开格不触雷，不保证邻格无雷，不验证可解性；后面可能需要猜。
- 首次开格才生成，随机打乱除首格外的所有格子，选出指定数量的雷。生成后不挪雷、不暗中保命。
- 简单数字提示不读取隐藏雷，也不把手动标旗当推理前提。没有确定步骤时明确提示可能需要猜。
- 支持右键标旗、手机开格 / 标旗切换、数字格开邻格、逻辑提示、双向滚动和大小调节。
- 存档 `aoinatsu:mines:v1` 含盘面、已开格、旗子和计时；加载只检查数据结构、雷数和数字，不检查是否可解。

测试：`node --experimental-strip-types scripts/test-table-games.mjs`，检查雷数、首点、标旗、输赢和存档，不再要求纯推理可解。
